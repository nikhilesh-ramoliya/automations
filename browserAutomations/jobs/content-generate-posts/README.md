# content-generate-posts

Reads `topics.json` from a content run, generates **3–5 angled LinkedIn posts per topic**, scores each draft, and persists them. **Never publishes.**

Angles: educational, founder insight, opinion, technical lesson, storytelling.

## Run

```powershell
# After research (same or explicit run id):
npm run jobs:run -- content-research-topics --dry-run
npm run jobs:run -- content-generate-posts --dry-run

# Or pipeline:
npm run content:pipeline -- --dry-run
```

Artifacts:

- `data/content/<runId>/drafts.json`
- `output/content/<runId>/drafts.json` + `drafts.txt`

## Draft fields

`topic`, `category`, `audience`, `interest`, `content`, `hashtags`, `score` (+ breakdown), `generatedAt`, `status` (`draft` / later `reviewed` | `published` by hand).

## Env

| Var | Default | Notes |
|-----|---------|--------|
| `CONTENT_MAX_VARIATIONS` | 4 | Clamped 3–5 |
| `CONTENT_MAX_TOPICS` | 8 | Cap topics expanded |
| `CONTENT_MIN_SCORE` | 55 | Reporting only; all drafts saved |
| `CONTENT_USE_AI` | true | LLM if key set |
| `OPENAI_API_KEY` | — | Optional |
| `CONTENT_RUN_ID` | latest | Must have topics |
| `CONTENT_INSTRUCTIONS_PATH` | `data/content/instructions.md` | Interests / Must / Never / Prefer |

## Instructions

Edit [`data/content/instructions.md`](../../data/content/instructions.md) — **Interests**, **Must**, **Never**.
- **Interests** = themes every topic/post should relate to (tracked in `data/content/interest-usage.json` for rotation).
Posts are generated by **Cursor CLI**: `agent -p --mode ask` (stdout only, no file edits).
Auth: `CURSOR_API_KEY` in `.env`, or `agent login`.

## Cadence

Recommended: **once daily** after topic research (external scheduler).
